# 商品展示小程序模板

基于微信原生小程序的商品展示 MVP，使用本地 mock 数据，不包含购物车、下单、支付或后台接口。

## 主题配色

当前使用商务科技蓝：品牌主色 `#356AE6`、深色文字 `#1D2B45`、浅灰蓝背景 `#F5F7FA`、白色卡片。底部导航普通态和选中态图标分别使用中性灰蓝和品牌蓝。

## 运行

1. 安装并打开微信开发者工具。
2. 导入本项目根目录。
3. 项目使用 `touristappid` 作为演示 AppID；正式预览或发布时请替换为自己的小程序 AppID。

## 已有页面

- 首页：品牌介绍、精选商品和搜索入口
- 分类：按商品分类筛选
- 搜索：按商品名称、分类和推荐语查找
- 商品详情：价格、介绍、规格和收藏
- 收藏：本地持久化的收藏列表
- 关于：店铺介绍和联系入口

## 替换演示内容

- 商品与分类：`miniprogram/data/products.js`
- 底部导航图标：`miniprogram/assets/tabbar/`，每个 Tab 配有普通态和选中态图标
- 商品卡片：`miniprogram/components/product-card/`
- 页面样式：各页面目录中的 `index.wxss`
- 店铺名称、品牌介绍和联系电话：对应页面的 `index.wxml` / `index.js`；联系电话默认留空，配置后才会触发拨号

当前商品封面使用渐变色与图形占位，接入真实图片时可在商品数据中增加图片字段，并将图片域名加入小程序后台的合法域名配置。

## 目录结构

```text
miniprogram/
  components/product-card/   可复用商品卡片
  data/products.js           商品与分类 mock 数据
  services/product.js        商品查询与本地收藏
  pages/                     首页、分类、搜索、详情、收藏、关于
```
